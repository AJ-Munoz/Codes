How the state machine works

The pet is a finite state machine with 10 states and 8 inputs, extended with four stats (food, energy, fun, health; 0–100, higher is better). Three things change its state:

  1. Inputs (your actions). The transition function δ(state, action, stats) looks up TRANSITIONS[state][action]. An entry is either a state, or a list of guarded rules such as [["tired","Sleepy"], [null,"Playful"]]: the first rule whose guard is true wins. Guards are checked before the action's effects change the stats.
  2. Automatic rules. Every tick, stat thresholds are checked in priority order: health<20 → Sick, food<15 → Hungry, energy<12 → Sleepy, Asleep & energy≥98 → Happy, fun<15 → Bored.
  3. Timers. Some moods wear off: Playful → Happy (12 s), Angry → Sad (15 s), Sad → Bored (25 s), Sleepy → Asleep (15 s), Drunk → Sleepy (10 s).
